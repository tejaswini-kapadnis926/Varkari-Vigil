# 🛕 Varkari-Vigil
### Smart Pilgrimage Safety & Management Dashboard

Varkari-Vigil is a web-based dashboard designed to support safer, smarter, and more organized Varkari pilgrimages. It brings essential pilgrimage management features together in one interactive interface, combining a spiritual visual experience with practical safety and coordination tools.

## ✨ Key Features

- **Interactive Operations Map** – View pilgrimage-related locations and operational information.
- **Risk Monitoring** – Explore risk indicators to support situational awareness.
- **Emergency Command Center** – A dedicated interface for emergency-related information and coordination.
- **Resource Management** – Organize and monitor essential resources.
- **Lost & Found** – Support the reporting and tracking of lost and found items.
- **Rest Finder** – Help identify rest and support locations.
- **Seva Index** – Present a consolidated view of service-related information.
- **Information Hub** – Keep important pilgrimage information accessible.
- **Cinematic UI** – Saffron, antique gold, and maroon styling with animated visual elements.

## 🧰 Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages for deployment

## 🎯 Project Objective

The objective of Varkari-Vigil is to demonstrate how a centralized digital dashboard can help organize pilgrimage information, improve situational awareness, and support safety-focused coordination during large religious gatherings.

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the project root.
3. Keep `vitthal.png` inside the `assets` folder.
4. Open `index.html` in a web browser.
